# Docki Explorer

VS Code / Cursor extension for browsing a repository `/knowledge` tree produced by Docki.

See the product docs: [`../../docs/explorer.md`](../../docs/explorer.md).

## Quick start

```bash
npm install
npm run compile
npm run package
cursor --install-extension docki-explorer-*.vsix
```

Or from the Docki root:

```bash
npx docki install-explorer
```
