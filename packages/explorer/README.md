# Docki Explorer

VS Code / Cursor extension for browsing a repository `/knowledge` tree produced by Docki.

Full product docs: https://github.com/MahmoudElderby/docki/blob/main/docs/explorer.md

## Quick start

```bash
npm install
npm run compile
npm run package
cursor --install-extension docki-explorer-*.vsix
```

Or from the Docki root:

```bash
npx docki-cli install-explorer
```
